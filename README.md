# shapeUp

אפליקציית תזונה ויעדי משקל ב־React Native וב־Expo.

## פתיחה בדפדפן

מתיקיית הפרויקט ובענף `feature/web-support`, הרץ:

```sh
npm ci --legacy-peer-deps
npm run web
```

פתח את הכתובת שמופיעה בטרמינל ובחר **Continue as a guest** כדי לגשת למסך הבית ולמחשבונים. חיפוש מזונות ומתכונים תלוי בשירותים החיצוניים שמוגדרים בפרויקט. ליצירת קבצים סטטיים מקומיים הרץ `npm run build:web`. הקבצים יופיעו בתיקיית `web-build`.

גרסת ה־Web מיועדת לבדיקה מקומית. לפני שימוש בחשבונות אמיתיים או פריסה ציבורית, יש לתקן את שמירת הסיסמאות בפרופיל ואת הרשאות Firebase.
